# 场景类型模板

## 标题场景（title）

用于开场。大图标 + 大标题 + 副标题逐行淡入。

```python
scene = {
    "type": "title",
    "title": "主标题",
    "subtitle": "副标题",
    "icon": "🤖",
    "lines": [],  # 可选
}
```

渲染逻辑：
- Icon 居中顶部（80px 字体）
- 标题居中（72px 粗体）
- 副标题延迟 30% 进度出现（40px，强调色）
- 额外行依次出现（36px）

## 内容场景（content）

用于正文。顶部标题栏 + 装饰线 + 内容逐行出现。

```python
scene = {
    "type": "content",
    "title": "场景标题",
    "icon": "🧠",
    "lines": [
        "一级标题行（不含 •）",
        "  • 二级要点",
        "     三级说明（缩进更多）",
        "",  # 空行增加间距
        "另一个一级标题",
        "  • 要点",
    ],
}
```

渲染逻辑：
- 标题栏：56px 粗体 + 装饰线（强调色）
- 一级标题（不含 `  •` 前缀）：38px 粗体，紫色
- 二级要点（`  •` 开头）：34px 常规，白色
- 三级说明（`     ` 开头）：30px 常规，灰色
- 非空行依次出现，间隔 `0.6 / 非空行总数`

## 警告场景（warning）

同内容场景，但装饰线和要点颜色为红色。

```python
scene = {
    "type": "warning",
    "title": "注意事项",
    "icon": "⚠️",
    "lines": [
        "❌  AI 不能替代临床判断",
        "     最终决策权在你手里",
    ],
}
```

## 结尾场景（ending）

同标题场景，但文字颜色为绿色，强调行动号召。

```python
scene = {
    "type": "ending",
    "title": "主标题",
    "subtitle": "副标题",
    "icon": "🚀",
    "lines": [
        "保持好奇",
        "大胆尝试",
    ],
}
```

## 配色速查

| 颜色 | RGB | 用途 |
|------|-----|------|
| 背景上 | (15, 23, 42) | 深蓝 |
| 背景下 | (30, 27, 75) | 深紫 |
| 强调蓝 | (56, 189, 248) | 装饰线/副标题 |
| 紫色 | (167, 139, 250) | 一级标题 |
| 白色 | (255, 255, 255) | 正文 |
| 灰色 | (148, 163, 184) | 三级说明 |
| 绿色 | (52, 211, 153) | 结尾文字 |
| 红色 | (248, 113, 113) | 警告要点 |
| 黄色 | (251, 191, 36) | 高亮 |
