# 表8 交付件版式验收（与模板逐像素对比）

适用：金医生反馈“表格右边距过大／与下方文字不对齐”“方框组位置不对”这类版式问题时。
原则：**先量，再看图**。像素测量给出可判定数值；视觉只用来看“整体像不像”。

## 1. 找到模板里表8 的页

```bash
for p in $(seq 1 20); do t=$(pdftotext -f $p -l $p 模板.pdf - 2>/dev/null | head -3 | tr -d '\n'); echo "$t" | grep -q "随访服务记录表" && echo "表8 第 $p 页"; done
```

实测：模板（`16、附件1-2严重精神障碍管理治疗工作用表.docx`）转 PDF 后表8 跨第 **14-15** 页；第14 页顶部还带着上一张表的注释行，所以模板表格的起始 y 比交付件低 ~90px。

## 2. 双方同分辨率渲染

```bash
soffice --headless --convert-to pdf <docx> --outdir /tmp/x
pdftoppm -png -r 150 -f 14 -l 15 模板.pdf tplP     # 模板对应页
pdftoppm -png -r 150 交付件.pdf final              # 交付件
```

150dpi 下 A4 = **1241×1754 px**。表8 表格左/右竖线应落在 **x=168 / x=1077**（模板与交付件必须相同）；下方注释文字左起 ≈188、右端 ≈1047。

## 3. numpy 量竖线 / 行线 / 方框组

```python
import numpy as np; from PIL import Image
im = np.array(Image.open(f).convert('L')); dark = im < 128
# 竖线：某列暗像素 > 页高*0.25
cols = [i for i in range(im.shape[1]) if dark[:, i].sum() > im.shape[0]*0.25]
# 行线：某行暗像素 > 表宽*0.5
rows = [j for j in range(im.shape[0]) if dark[j].sum() > (1077-168)*0.5]
```

**方框组识别**：逐行取宽 **8-32px** 的暗线段，一行里出现 ≥4 个即为“方框串行”；相邻 3 行内合并为一组。判据：

- 症状 12 框组右端、康复 5 框组右端都应距表格右竖线（1077）**13px**（模板症状行 x=665..1064）。
- 差值明显偏大（如 34px 以上）说明只设了 `jc=right` 而没补 `w:ind w:right="-200"`。

## 4. 给金医生看的对比图（带参考线）

把模板与交付件的对应区域裁成同宽横带（x 范围取一致，如 150..1115），在每条带上按表格右竖线画一条红线，纵向拼接并标注“模板／交付件”。交付时给两张：整页对比（缩到 ~0.52）+ 行级放大带。

```python
d.line([(1077-X0,0),(1077-X0,b.height)], fill=(255,0,0), width=2)
```

**坑：不要按 y 坐标配对两文档的行。** 模板第14页顶部多了上一张表的注释，且两文档行高微差，同一行的 y 差可达 90-230px；按 y 裁会裁到别的行（曾把模板的“用药指导”行当成“康复措施”行，得出错误结论）。配对依据用行的内容特征（方框串的段数/宽度、选项文字），或先把两边渲染成图目视定位后再裁剪。

## 5. 其它判定量

- **“表格右边距过大、与下方文字不对齐”** = 表格右竖线不是整页最右内容，或与下方文字右端差 >20px → 查页边距节（见 SKILL.md 规则 11）。
- 交付件第 2 页只剩注释最后一行（“修订，以*标注，填表说明略。”）是当前模板布局的正常结果，不是错误；若要压成单页需改注释段行距（会动模板排版，先问金医生）。
