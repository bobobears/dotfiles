# 年度职工培训计划编制

## 触发场景
用户要求编制某一年度的职工培训计划（如“2027年培训计划”），要求包含：固定周期排课、每课题配可访问链接、覆盖规定主题、必修课指定专人授课。

## ⚠️ 头号坑：用户要的“链接”通常是**网课/教学视频链接**，不是法规原文文件链接
- 默认理解：除必修课（专人面授）外，其余课程应挂**在线课程/教学视频**链接（中国大学MOOC、国家高等教育智慧教育平台等）。
- 不要默认堆一堆 gov.cn 法规全文链接——那不是“网课”。如不确定，先问一句“要文本资料链接还是教学视频链接”。

## 工作流

1. **算出全年排课日**（如每周一）：用 Python 计算，并标出与法定节假日冲突的日期。
   - 春节/清明/劳动节/国庆 常落在周一。**遇法定节假日的周次直接不排课，不顺延**（用户偏好）；全年课次 = 周一总数 − 节假日周数。
   - 例：2027年52个周一中有4个在节假日（2/8春节、4/5清明、5/3劳动节、10/4国庆），实际排48课次。
   - 官方放假安排通常上年11月才公布，未公布时按惯例预估，并在文档说明中注明。
2. **确定主题清单**：按类别分组（医疗基础、临床技能、公卫服务、政策法规）+ 必修课。
3. **为每课题配链接并逐条验证**（核心要求，见下）。
4. **生成文档**：Word（`.docx`，纵向叙述 + 横向课程表分节）+ Excel（`.xlsx`，带超链接、冻结窗格、筛选）。
5. **复核**：回读 docx/xlsx 校验行列数，并对全部链接做最后一次 200 复核。

## 网课链接检索（医学/公卫类）

首选平台（均国内可直连）：
- **中国大学MOOC**（icourse163.org）——最丰富，课程 URL 形如 `/course/<学校码>-<数字>` 或 `/learn/<学校码>-<数字>`。
- **国家高等教育智慧教育平台**（higher.smartedu.cn）——教育部官方，课程 URL 形如 `/course/<24位hex>`。
- 学堂在线、人卫慕课、医学微视、智慧职教（icve.com.cn）。

检索方式：`web_search("中国大学MOOC <课程名> 课程")`，再用 curl 校验。

### 已验证课程清单见 `references/mooc-courses.md`（50门，2026-09核验）

## 链接验证（关键）

- 用 `curl -sS -L --compressed -o /dev/null -w "%{http_code}"` 批量测；**必须带浏览器 UA + Accept-Language**，否则政府站会拒绝。
- **要校验正文关键词**，不能只看 200：很多旧 URL 会 302 到网站首页（返回 200 但是无关内容）。用 `curl` 取正文确认包含主题关键词。
- icourse163 的课程页：正常返回约 80–130 KB 且 `<title>` 含“_学校_中国大学MOOC(慕课)”；若 <20 KB 则为无效页。用正则抽 `<title>` 做内容校验最省事。
- 只要 PDF/静态文件，忽略 412/403 的 `.shtml` 页面。

### 已知域名可达性（本机实测）
| 可用 | 被 WAF 拦截（curl 412 / 浏览器空白） |
|------|--------------------------------------|
| gov.cn、mem.gov.cn、mee.gov.cn、nhsa.gov.cn、chinacdc.cn、mohrss.gov.cn、samr.gov.cn、csbt.org.cn、省级政府网站 | **nhc.gov.cn（国家卫健委）、nmpa.gov.cn** |

- `www.nhc.gov.cn` 从本机 **完全不可达**（含真实浏览器）。但其 **PDF 静态文件路径**（`/ewebeditor/uploadfile/...pdf`）可正常 200 → 卫健委文件优先找 PDF 版本。
- nhc 的 `.shtml` 正文页取不到时，改用替代源：省级政府/卫健委网站、中国政府网、国务院公报、国家疾控局(ndcpa.gov.cn)、行业协会、医学期刊。
- 国家法律法规数据库 `flk.npc.gov.cn` 已改版为 SPA，旧检索 API 失效，链接为动态 ID，不适合做静态引用。

## 生成文档的要点

- python-docx：正文宋体、标题黑体，需 `r._element.rPr.rFonts.set(qn("w:eastAsia"),"宋体")` 才显示中文；用 `doc.add_section()` + `WD_ORIENT.LANDSCAPE` 做横向表格页。
- openpyxl：链接列设 `cell.hyperlink`，行高/列宽按内容设，`freeze_panes` + `auto_filter`。
- 预览：`soffice --headless --convert-to pdf` + `pdftoppm -png -r 90 -f 1 -l 3`，再 `vision_analyze` 检查排版。

## 坑

- 政策文件会更新换代（如《临床输血技术规范》已被《临床用血技术规范（2025年版）》取代），编制新年度计划时要检索**最新版本**，不要沿用旧文件名。
- 不要编造授课人姓名；用岗位/科室占位（如“医务科（专人）”），并注明名单由培训领导小组年初确定。
