# 持仓体检与配置建议

## When to Use

- 「要不要出 / 能不能补 / 要不要换股 / 还是观望」
- 「我这个配置合理吗」「仓位怎么调」
- 「帮我看看持仓卖点」「XX 该不该卖」
- 报出持仓与盈亏（如「只剩某股 20 手、盈利 5000+」）并要求建议
- 定期体检（月末、财报季前后）
- **每日/每周持仓卖点监控**：主动拉 sell_rules 对照三层防线，触发即报警

不适用：单纯查行情、解读某只股票的财报数字（那走 `chinese-stock-data`）；**问「哪个板块接替龙头/轮动去哪」也不走本 skill**——那是跨板块横向比较，方法在 `chinese-stock-data` 的「板块轮动分析」章节（ETF 代理 + 250 日五指标横排）；本 skill 只在拿到板块结论后负责「你的仓位怎么配」。

金医生是「长线 ETF 持有 + 个股量化」双策略投资者，会周期性地问：
「要不要出？」「能不能补？」「出清后观望还是换股？」「我这个配置合理吗？」

这类问题的答案不是「看好/看空」，而是一张**带条件触发的动作表**。取数用 `chinese-stock-data`（行情/财报/披露日）、`a-share-etf-analysis`（ETF 净值与持仓）。

## 卖点三层防线（核心纪律）

金医生买点手感好，**卖点靠纪律不靠感觉**。每次分析持仓，先过三层防线再给结论。

### 第一层：硬止损（铁律，无条件执行）

| 风格 | 止损幅度 | 触发 | 执行 |
|:---:|:---:|:---|:---|
| 短线 | 买入价 -7% | 收盘价 ≤ 止损价 | 卖 1/3~1/2，不找理由 |
| 中线 | 买入价 -12% | 收盘价 ≤ 止损价 | 卖 1/3~1/2 |
| 长线 | 买入价 -20% | 收盘价 ≤ 止损价 | 卖 1/4 |
| ETF | 买入价 -8% | 收盘价 ≤ 止损价 | 卖 1/3 |

**触发即卖，不抱侥幸。** 不全清，留余地防 V 反。

### 第二层：移动止盈（锁住利润）

从持仓期间**最高价**（high water mark）往下回撤一定比例时触发。HWM 只升不降，每创新高就更新止损线上移。

| 风格 | 回撤幅度 | 执行 |
|:---:|:---:|:---|
| 短线 | 高点 -8% | 卖 1/3 |
| 中线 | 高点 -12~15% | 卖 1/3 |
| 长线 | 高点 -20% | 卖 1/4 |
| ETF | 高点 -12~15% | 卖 1/3 |

**核心原则：绝不把浮盈坐回去。**

### 第三层：信号止盈（技术+基本面共振）

满足以下**任意 2 条**→ 减仓 1/3；**3 条以上**→ 减仓 1/2：

1. RSI14 > 80（短线 > 75）
2. 量价背离：股价创新高但量比前高缩 30%+
3. 均线破位：收盘破 MA20（中线）/ MA60（长线），次日不收回
4. 板块转冷：所属板块连续 3 日跑输沪深 300
5. 基本面恶化：业绩下修、政策利空、大股东减持
6. 估值泡沫：PE 分位 > 90%（5 年历史）

### 特殊卖出信号

- **利好出尽**：重大利好兑现日（财报超预期/政策落地/重组完成）→ 当天或次日冲高减 1/3
- **时间止损**：中线 60 交易日未盈利 → 审视逻辑；长线 12 个月基本面证伪 → 无条件离场
- **仓位过重**：单只 > 30% → 先减到 25%；单板块 > 50% → 减最弱一只
- **替代机会**：发现明显更优标的 → 可换仓，但只在确信度高时

### 数据库：sell_rules 表

`~/private_db/private.db` → `sell_rules` 表，每只持仓一条记录：

| 字段 | 说明 |
|:---|:---|
| code / name | 代码 / 名称 |
| style | 长线/中线/短线/ETF |
| entry_price / entry_date | 成本 / 买入日 |
| stop_loss | 硬止损价 |
| take_profit | 止盈目标价 |
| trailing_pct | 移动止盈回撤 % |
| high_water | 历史最高价（每次新高时更新） |
| time_stop_date | 时间止损到期日 |
| signal_rules | 技术信号规则 (JSON) |
| active | 1=持仓中 0=已清仓 |

**每次分析持仓时必须**：① 拉 sell_rules 对照三层防线；② 更新 high_water；③ 触发则更新 active。

## 五步流程

### 1. 给每个标的定位：分位 与 估值 必须分两步

- **分位**（`(现价−一年低)/(一年高−一年低)`）只回答「在区间哪一段」，**不等于贵贱**。
- **估值**（银行看 PB/PE/股息率，成长看 PE/PS 分位，宽基看 PE 分位）回答「贵不贵」。

高股息价值股站在 85% 分位仍可能是「位置高但估值不贵」（PB 0.8、股息 5%）；成长股在 15% 分位只能说「跌了很多」，不等于便宜。**把两者混起来说「全场最贵」是错的**。

### 2. 查集中度（最容易出问题的地方）

| 层级 | 上限 | 判断 |
|---|---|---|
| 单一赛道 | ≤ 35% | 超过就是押注单一叙事（如 AI），泡沫争论期风险放大 |
| 单一个股 | ≤ 5% | 超过则单票黑天鹅能伤到组合 |

常见的结构错配：**成长类在低位、防御类在一年高位**。这时不该「卖掉涨的、去追跌的」，而要看两者的估值是否匹配位置。

### 3. 看市场位置决定总仓位档位

先查指数一年分位 + 均线结构（是否全部跌破 / 站上 MA20），再给档位：

| 市场情形 | 仓位 |
|---|---|
| 底部区域、但未确认反转（均在均线下方） | 5-6 成 |
| 放量站上 MA20 且持续数日 | 7-8 成 |
| 跌破前低（关键支撑失效） | 3-4 成 |

**单日深 V 反转 ≠ 趋势反转**，一律按「反弹」对待，直到站上 MA20。

### 4. 查财报日程，避开雷期

三季报/年报密集披露期（10 月底、4 月底）不追新票——业绩雷与大盘无关（本会话实例：全市场深 V 反弹，某水电股当天收 −6.7%、几乎最低）。想加仓先看该标的的披露日历。

### 5. 给三档动作 + 纪律线

**纪律线必须以用户成本价为锚。** 用户常只说「盈利 5000+」或「20 手」，先反推成本再谈纪律：

```
成本 = 现价 − 盈利 / (手数 × 100)
```

然后给：

| 触发 | 动作 |
|---|---|
| 涨到 X（前高/压力位） | 减半 |
| 跌破 Y（MA60/关键均线） | 减到半仓以下 |
| 跌破成本价 | 无条件离场 |

**用户明确拒绝「模糊建议」**：给「建议减仓」不如给「涨到 9.60–9.62 减一半、跌破 8.86 全清」。

## 新仓入场择时（「今天进 X 合适吗」——非持仓决策）

用户问「今天进这只 ETF/股票合适吗」时，是**新仓建仓择时**，不是持仓处置。给**分批入场方案**，不给「买/不买」二选一：

1. **先定位**：取近月 K-line（`a-share-etf-analysis` Phase 5），算高点回撤%、近月支撑区（多次探底价格带）、MA20 位置。
2. **判断当日性质**：逆市走强 + 从底部反弹 + 资金从另一板块外溢（跷跷板）→ 短期逻辑成立；但**单日反弹 ≠ 趋势反转**，板块内部结构分化（部分成分涨部分跌）= 资金在挑、不是无脑冲。
3. **给分批**：
   | 档位 | 位置 | 仓位 |
   |---|---|---|
   | 第一批 | 现价附近（若逆市走强+超跌反弹逻辑成立） | 30% |
   | 第二批 | 回踩支撑区（近月多次探底带） | 60-70% |
   - 不建议一把梭的原因：反弹第一天未确认企稳、内部结构分化、中期趋势未扭转（近3月仍为负）。
4. **长线风格兜底**：金医生是长线 ETF 持有者，给出**建仓区间**（如 0.60-0.63）而非纠结一两天——核心逻辑（订单周期/资金外溢）没变就不因单日波动劝退。

**别在反弹第一天喊反转**：仓位档位跟着「站上 MA20」这类硬信号走，单日 +1% 反弹只够上第一批，不够打满。

## 常用折中方案：卖一半

已盈利 + 位置偏高 + 估值不贵 + 两三天内有财报 → **卖一半、留一半过财报**，按结果决定剩下的一半（超预期留、符合预期减半、不及预期全清）。全清会错过防御行情，不动则在高位承担回撤。

## 分批补仓：三档，不要一次打满

| 档位 | 位置 | 仓位 |
|---|---|---|
| 第一档 | 前低上方 1-2% | 计划量 30% |
| 第二档 | 中间缓冲 | 30% |
| 第三档 | 一年低点附近 | 40% |

**跌破一年新低就停止补仓**——那是趋势级别破坏，不是继续摊平的信号。

## 输出格式（用户偏好）

1. **表格先行**：标的 ｜ 收盘 ｜ 当日 ｜ 距一年高 ｜ 一年分位（用 🟢/🟡/🔴 标）
2. **一句话指出结构问题**（如「成长在低位、唯一持仓却在高位」）
3. 三档动作表 + 纪律线
4. 结尾一句结论（把关键位和动作压成一句话）

不要写成长篇宏观论述——他要的是「明天照这个执行」。

## Pitfalls

- **别把分位当估值**（见步骤 1），也别把「跌得多」当「便宜」。
- **防御仓 ≠ 新龙头，别重复配置**：用户已持有红利/银行类 ETF 时，它在大盘下跌日天然抗跌（避险属性），已经起对冲作用——结论是「持有即可」，不要再建议加仓同一类防御品；新增仓位应看低位进攻型板块，且只给条件触发（放量站上 MA20），信号未出现就写「记入观察列表」。
- **板块结论落到持仓时区分两档时间尺度**：短期（1-3 月）防御结构赚的是「别人跌我不跌」的钱，中期进攻接替者需要大盘先收复 MA20 才有环境；总仓位纪律（大盘收复 MA20 前新仓合计 ≤20%）压在动作表最后一行。
- **别在反弹第一天就喊反转**，仓位档位要跟着「站上 MA20」这类硬信号走。
- **别劝人一次打满或一次清仓**——分批是这类咨询的默认答案。新仓入场同理：逆市走强也只上第一批（~30%），回踩支撑再补。
- **新仓入场 vs 持仓处置别混**：「今天进 X 合适吗」给分批建仓区间（现价 30% + 支撑区 70%），「持仓 X 要不要卖」给三档纪律线——两套输出格式不同，别套错。
- **板块内部结构分化要拆开说**：成分股有涨有跌时（如军工主机厂涨、卫星/航天电器跌），明确写「结构性上涨，资金在挑核心」，别笼统说「板块普涨」。
- **别忘成本价**：用户报「盈利 N 元」时一定要反推成本，否则纪律线没有锚点。
- 引用个股数据前按 `chinese-stock-data` 的字段顺序自查表核一遍（新浪/腾讯/东财偏移各不同）。
