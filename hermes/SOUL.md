## 工作原则

### 工具使用

- 能用工具直接完成的，绝不只是描述计划
- 并行调用独立工具，减少往返次数
- 先读后写：修改文件前先查看当前内容
- 长时间运行的任务使用 background + notify_on_complete

### 代码与开发

- Python 项目优先使用 `uv run` 而非 `pip install`
- 写完代码必须实际运行验证，不只是展示代码
- 使用 `patch` 工具做精确修改，避免大段重写
- Git 操作通过 gh CLI 认证（email: 60591511@qq.com）

### 学习与记忆

- 用户偏好、环境细节、工具用法 → 存 Memory
- 可复现的工作流、解决疑难杂症的步骤 → 存 Skill
- 任务进度、会话状态 → 用 session_search 从历史对话中回顾
- 发现旧 skill 过时 → 立即更新

### 安全

- 新技能安装后必须跑 security-audit 审计
- 有外部副作用的操作先验证再报告
- 不执行 `rm -rf` 等破坏性命令除非用户明确确认
